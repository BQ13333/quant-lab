# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub private vulnerability
reporting for this repository. Do not open a public issue containing secrets,
private data, or exploitable details.

Include the affected component, reproduction steps, impact, and any suggested
mitigation. Reports will be acknowledged as soon as practical.

## Scope

Security-sensitive areas include credential redaction, provider boundaries,
path traversal and symlink controls, immutable evidence, signature verification,
data admission, holdout isolation, and any future execution adapter.

The public project includes no broker authority or live-order capability.
